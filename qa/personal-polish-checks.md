# 개인 메뉴 폴리싱 확인 — 2026-10-13

## 범위

- 전체 메뉴의 기존 항목, 85% 미리보기 높이, 모션, 기존 터치 영역 규칙을 유지했다. 별도 운영자 대시보드는 변경하지 않았다.
- 내 활동은 내 글·내 댓글·문제 알린 내역으로 구성하고 반복 프로필을 제거했다.
- 내 설정은 프로필 정보·로그인 정보로 나눴다. 변경 전 저장 비활성화, 변경 취소, 미저장 이동 확인, 저장 중 중복 요청 방지, 오류 시 입력 유지를 적용했다.
- 저장한 글·자료는 항목별 해제와 마지막 해제의 실행 취소를 지원한다. 큐시트 읽던 위치는 기존대로 현재 기기에 보관된다.
- 알림에 원글 제목과 댓글 일부를 표시한다. 읽을 수 있는 글·댓글만 기존 RLS를 통해 조회한다. DB 스키마·권한 변경은 없다.
- 이전에 숨긴 회원이 있을 때만 설정에서 숨김 해제를 제공한다. 새 숨기기 기능은 추가하지 않았다.

## 자동 검사

- `npm run check`: TypeScript, 5,330개 문서·66,010쪽, 보존 이미지 해시 71개 검사 통과.
- `npm test`: 146개 통과. 알림의 비공개·삭제·다른 글 댓글 제외와 비밀번호 재설정 복귀 주소 검증 포함.
- `npm run build`, `npm run check:performance`: 통과. 기존 큐시트 3D 모듈의 500 kB 안내는 유지되며 해당 모듈은 지연 로딩된다.
- `qa/personal-polish.html`: 가짜 계정·요청을 사용하는 22개 회귀 검사. 320×568, 390×844에서 모두 통과.
- 회귀 검사는 미저장 이동 취소/허용, 백그라운드 프로필 갱신, 저장 중 이동 차단, 저장 실패 시 입력 유지, 큐시트·게시글 해제/복원, 중복 요청, 가로 넘침을 포함한다.

## 브라우저 확인

- Supabase에 연결하지 않은 로컬 체험 서버(5221)에서 일반회원으로 확인했다.
- 320px: 전체 메뉴의 프로필 안내 문구를 두 줄로 정리했다. 전체 메뉴 구성과 85% 미리보기 높이를 유지했다.
- 내 댓글 2페이지 → 로컬 검증 댓글 15 → 내 활동 복귀 시 `tab=comments&page=2` 유지.
- 알림 → 지정된 답글이 화면 안에 표시 → 원래 알림 목록 복귀.
- 큐시트 저장 해제 → 실행 취소 → 원래 항목 복원. 큐시트/게시글 탭과 읽던 위치 표시 정상.
- 비회원의 개인 화면은 로그인 안내를 표시하고, 체험 로그인 후 요청한 개인 화면으로 복귀했다.
- 실제 화면에 가로 넘침 없음. 앱 전용 검사 탭의 콘솔 오류 없음. 회귀 검사 탭의 개발 중 HMR/React act 안내는 별도로 구분했다.

- 운영 DB에서는 알림 확장 조회에 필요한 SELECT 권한과 기존 공개/비밀글 RLS만 읽기 전용으로 확인했다.
