# UX 기록 보완 검수 — 2026-10-14

대상은 `codex/voku-ux-study`와 `voku-ux-study.pages.dev`다. 운영 `main`과 `voku.pages.dev`, 공유 회원·게시글 DB는 수정하지 않는다.

## 변경

- 시간 고리 원고 미리보기, 이전·다음 연도와 최종 선택 연도, 자료 경로·최근 본 큐시트, 홈 더보기, 이어 읽기 등 누락된 클릭을 고정 기능 코드로 기록한다. 제목·검색어·주소는 전송하지 않는다.
- 체험 로그인·로그아웃, 추천·저장·공감, 공유, 데이터 요청, 이미지 표시, 확대·회전·쪽 이동의 처리 결과를 클릭과 분리한다. 글쓰기 제한도 결과로 표시한다. 예외 원문은 저장하지 않는다.
- 스크롤은 직접 입력, 자동 위치 이동, 원인 미확인으로 구분한다. 자동 이동은 읽던 위치 복귀, 버튼 이동, 화면 이동, 배치 조정으로 더 나눈다. 변경 없는 문서 높이는 스크롤로 기록하지 않는다.
- 관리자 화면은 결과 집계와 스크롤 구분을 제공한다. 기존 스크롤은 원인 미분류로 유지하고 과거 결과를 추정하지 않는다.
- 기존 방문 ID·이벤트 순번과 DB 구조를 유지한다. version 1·2 수집 호환성을 유지하며 이번 작업에는 DB 마이그레이션이나 기록 삭제가 없다. 기존 30일 보관 정책은 그대로다.

## 로컬 검증

- 자동 테스트 188개 통과: 고정 코드 분류, 스크롤 원인·관성·경로 전환, 이전 형식 호환성, 허용 값 검증, SQLite 기존 행 보존·중복 수집 방지, 운영 호스트 강제 비활성화 포함.
- `npm run check` 통과, 프로덕션 빌드 성공.
- 390×844에서 실제 2018년 아침식당 원고를 시간 고리 미리보기로 열었다. D1에서 미리보기 클릭 → 원고 진입 → 페이지 목록·이미지 성공을 확인했다.
- 실제 확대(100→125%), 회전, 3쪽 이동의 클릭·완료 기록을 각각 확인했다. 직접 스크롤 후 저장한 4쪽 이어 읽기는 자동 위치 복귀로 구분했다.
- 큐시트 스크랩·해제는 체험 회원의 탭 상태만 바뀌었다. 글쓰기 차단은 유지한다.
- 320px에서 홈·전체 메뉴의 가로 넘침이 없었고, 더미 로그아웃·카카오 체험 로그인 뒤 원래 홈으로 복귀했다. 각각 `auth.logout`·`auth.demo` 완료를 로컬 DB에서 확인했다.
- `qa/ux-measurement.ts` 로컬 전용 재현 화면으로 요청 성공·실패, 공유 취소, 복사 성공·실패, 실제 이미지 load/error, 자동 복귀 후 실제 스크롤을 확인했다. 이 재현 화면은 배포 빌드에 포함하지 않는다.

## 해석 범위

공유 API의 Promise 완료 시점은 기기마다 다르므로 상대방 전달 성공으로 보지 않는다. [MDN Web Share 설명](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)을 따른다. 직접 스크롤도 내용을 읽었다는 증거는 아니며, 알 수 없는 이동은 직접 스크롤로 추정하지 않는다.
