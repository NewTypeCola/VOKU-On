# 홈 탭 개편 — 2026-10-11

## 현재 범위

기존 React 라우팅과 커뮤니티 API를 유지한다. 홈을 배너 → 공지 → 인기 이야기 → 사진으로 보는 추억 → 동문 소식 → 최근 올라온 글 → 글쓰기 순서로 구성했다. 회원·인증·관리자 기능은 이 작업에 포함하지 않는다.

사용자가 로컬 화면을 확인한 뒤 2026-10-11에 전체 테스트와 커밋·푸시·운영 배포를 승인했다. 홈 외의 기존 공통 모션 변경은 작업 폴더에 보존하고 이번 배포 범위에서는 제외한다. 개발 화면, 배포용 빌드 검증, 실제 운영 배포 결과를 구분한다.

## 홈에서 좌우 스와이프

- 홈 본문을 오른쪽으로 밀면 왼쪽의 `큐시트 찾기`, 왼쪽으로 밀면 오른쪽의 `커뮤니티` 탭으로 이동한다. 누른 채 움직이는 동안 홈 화면이 손가락을 따라 밀리고 실제 옆 탭이 드러난다. 충분히 밀고 놓으면 두 화면이 함께 밀려 전환을 마무리하고, 짧게 밀거나 취소하면 제자리로 돌아온다.
- 옆 탭은 스와이프 방향이 정해질 때만 미리 표시하며 입력은 비활성으로 둔다. 전환 후에는 같은 컴포넌트를 그대로 사용해 목록을 다시 불러오거나 화면이 깜빡이는 것을 피한다. 스크롤한 홈에서도 고정 탭 아래에 목적지의 첫 내용을 맞추고, 브라우저 뒤로 가면 홈의 원래 목록·스크롤 위치로 복귀한다. 기기의 동작 줄이기 설정에서는 놓은 뒤의 자동 이동 애니메이션을 생략한다.
- 홈 본문에만 터치 처리를 연결한다. 큐시트·커뮤니티·게시글 화면에는 탭 이동 제스처를 추가하지 않는다. 배너는 자체 스와이프를 유지하고 버튼·입력 컨트롤은 제외한다.
- 가로 이동이 세로 이동보다 충분히 큰 72px 이상의 한 손가락 동작만 처리한다. 세로 스크롤·짧은 터치·길게 누르기·두 손가락 확대·선택한 텍스트·확대한 화면·브라우저 가장자리 제스처를 보호한다. 취소된 동작이나 원위치로 돌아온 드래그는 이동하지 않는다.
- `node --test scripts/home-swipe.test.mjs scripts/home.test.mjs scripts/community-navigation.test.mjs scripts/loading.test.mjs scripts/reader.test.mjs`: 36개 통과. `npm run check`와 빌드도 통과했다.
- 로컬 `qa/home-swipe-smoke.html`에서 실제 홈 컴포넌트에 합성 터치 이벤트를 보내 양방향 이동, 다른 탭에서 비활성, 뒤로 가기, 배너·버튼·세로 스크롤·다중 터치·가장자리·링크를 검사한다. 손가락을 따른 이동 거리, 화면 사이의 틈, 짧은 드래그 복귀, 전환 뒤 같은 컴포넌트 유지, 깊은 스크롤 위치 정렬, 취소된 전환의 뒤늦은 실행 방지도 포함한다. 개발 화면과 이번 변경만 포함한 운영 빌드의 320·390px 화면에서 14개 모두 통과했다. 물리 휴대폰 검증과는 구분한다.
- 기존 미커밋 공통 모션 변경이 포함된 개발 빌드는 CSS 용량 제한을 초과하므로, 배포 검증은 현재 배포된 소스에 이번 스와이프 변경만 더한 별도 디렉터리에서 수행했다. 해당 빌드는 기존 성능 예산과 로컬 예시 제외 검사를 통과했다.

## 이미지 배너

- 기존 1개에 큐시트·추억·동문 소식 예시를 더해 총 4개다. 글자가 이미지 자체에 포함되어 있다.
- `src/home/banner.ts`에서 순서·이미지·대체 텍스트·이동 경로를 설정한다. 활성 배너는 최대 10개다. 업로드나 관리자 화면은 추가하지 않았다.
- 기본 자동 간격은 10초다. 다음 이미지가 옆에서 들어오며 현재 이미지를 밀어내는 전환을 사용한다. 마지막 배너에서 첫 배너로 갈 때도 같은 방향을 유지한다.
- 이미지 아래의 설명·이전/다음·숫자 줄은 제거했다. 이미지 안쪽 하단 중앙의 점으로 전체 개수와 현재 배너를 표시하고, 하단 우측에는 정지/재생 버튼을 둔다. 점과 버튼에는 배경을 쓰지 않고 얇은 그림자만 둔다. 시각 요소는 아래쪽에 가깝게 배치하되 정지 버튼의 터치 영역은 44px로 유지한다.
- 점 직접 선택, 좌우 스와이프, 키보드 좌우 이동을 지원한다. 키보드 초점, 마우스 올림, 터치 중, 화면 밖, 비활성 탭에서는 자동 넘김을 멈춘다. 동작 줄이기 설정을 쓰면 자동 넘김을 꺼서 시작하며 수동 이동의 슬라이드 애니메이션도 생략한다.
- 큐시트로 가는 별도 바로가기 줄은 배너로 합쳤다. 기존 큐시트 탭은 그대로다.
- 현재 배너와 로컬 예시 사진은 built-in `image_gen`으로 만든 합성 이미지이며 실제 소장 자료가 아니다. 서비스용 JPEG는 `public/home/`에 저장했다. 새 이미지의 정확한 생성 프롬프트는 `src/home/generated-assets.json`, 첫 배너의 프롬프트는 `src/home/banner.ts`에 보존했다.

## 인기 이야기

참고한 공식 그누보드7 구현:

- [인기글 쿼리](https://github.com/gnuboard/g7/blob/main/modules/_bundled/sirsoft-board/src/Repositories/BoardRepository.php#L487): 기간에 작성된 공개 글을 누적 조회수 내림차순, 동률이면 댓글 수 내림차순으로 정렬한다. 비밀글·삭제글·답글은 제외한다.
- [인기글 화면](https://github.com/gnuboard/g7/blob/main/templates/_bundled/sirsoft-basic/layouts/board/popular.g7.html): 오늘·주간·월간·연간 기간 선택이 있다.

사용자 피드백에 따라 기간은 **최근 7일로 고정**했다. 기간 선택기, 상자 형태의 큰 버튼, 별도의 집계 설명 줄, ‘선정 기준’ 펼치기는 제거했다. 제목 옆에 최근 7일을 짧게 표시하고 그 아래 ‘많이 본 글 / 댓글 많은 글 / 인기 큐시트’를 한 줄의 작은 텍스트 탭으로 배치한다. 선택한 목록만 같은 영역에 표시하며 별도 큐시트 순위 코너를 만들지 않는다.

탭은 **25초마다** 많이 본 글 → 댓글 많은 글 → 인기 큐시트 순으로 순환한다. 선택된 탭의 아래 선이 같은 시간 동안 차오르고 목록은 짧게 나타나는 전환을 사용한다. 탭을 직접 고르면 25초를 새로 시작한다. 제목 옆의 정지/재생, 마우스 올림, 키보드 초점, 터치 중, 탭 선택 줄이 화면 밖에 있을 때, 비활성 브라우저 탭에서는 진행바와 타이머를 함께 멈추고 남은 시간을 유지한다. 목록을 펼쳤거나 자료를 불러오는 동안에도 넘어가지 않는다. 동작 줄이기 설정이면 자동 넘김은 꺼서 시작하고 진행바는 고정된 선택선으로 표시한다. 자동 전환은 현재 URL을 교체해 브라우저 방문 기록을 쌓지 않는다.

조회수 동률은 댓글 수, 댓글 수 동률은 조회수로 비교하며, 둘 다 같으면 추천 수·작성일·ID로 순서를 안정화한다. 기간은 **작성 시점**에 적용하고 조회·댓글 수는 **누적 수치**다. 공지·비밀글·비공개 상태의 글을 제외하며, 선택한 반응이 0인 글을 최신글로 대체해 넣지 않는다. 글은 처음 5위까지, 해당 글이 충분하면 같은 기준으로 10위까지 펼친다. 선택한 탭은 홈 URL의 `rank=views|comments|episodes`에 남겨 읽고 돌아올 때 유지한다. 과거 `period=30` 링크에서도 기간은 7일로 고정하며, 탭을 바꾸면 불필요한 기간 파라미터를 지운다.

현재 로컬 구현은 기존 `community_feed`의 최신순 페이지를 순회해 최근 7일의 글을 모은다. 요청량을 제한하려고 최대 10페이지(200개)까지만 읽으며, 기간 내 후보가 더 있을 때만 수집한 개수 기준임을 목록 아래 표시한다. 현재 소규모 데이터 확인에 사용하는 방식이다. 운영 규모가 커지기 전에 같은 공개 범위와 정렬 기준을 서버의 집계 쿼리로 옮기는 것이 후속 과제다. 이번에는 DB나 서버 함수를 변경하지 않았다.

### 인기 큐시트 탭

최근 7일에 작성된 공개 게시글의 `recordId` 연결을 회차별로 집계해 최대 3개를 표시한다. 같은 글은 한 번만 센다. 연결글 수가 같으면 가장 최근에 연결된 회차가 먼저 나오며, 그래도 같으면 자료 ID로 순서를 안정화한다. 본문에 자유롭게 적힌 회차명이나 댓글 속 언급은 추측해서 집계하지 않는다. 따라서 화면에는 ‘언급 수’ 대신 **연결글 수**를 표시한다.

회차명·연도·학기·회차 번호는 보존된 실제 자료 목록에서 확인하며, 목록에 없는 ID는 노출하지 않는다. 예시 게시글에서 온 연결은 예시 표시를 유지하고 로컬 사진 예시 3개는 집계에 포함하지 않는다. 공개글과 연결 회차가 적으면 실제 집계된 개수만 표시한다.

방문 흐름은 홈의 인기 큐시트 선택 → 기존 연속 원고 열람 → 홈의 같은 탭과 스크롤 위치로 복귀다. 자료 목록은 이 탭을 열었고 연결 회차가 있을 때만 불러오며, 홈의 다른 코너를 자료 로딩으로 막지 않는다.

## 사진·최신글

- 사진 코너는 2열, 최대 4개다. 사진이 붙은 기존 추억 글 1개와 로컬 예시 3개로 현재 구성을 볼 수 있다.
- 예시 3개는 `import.meta.env.DEV`에서만 노출한다. 홈에서 상세 글과 사진 확대를 열 수 있고 `로컬 예시`를 표시한다. DB·스토리지에 등록하지 않으며 최신글·인기글이나 반응 집계에도 섞지 않는다.
- 실제 사진 글이 늘면 실제 글부터 최대 4개를 표시한다. 운영용 화면에는 로컬 예시를 포함하지 않는다.
- 최신글 코너는 다른 코너와의 중복 여부와 무관하게 실제 작성순을 유지한다. 중복 제거 때문에 최신 글이 사라지는 혼동을 없앴다.
