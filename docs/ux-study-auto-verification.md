# UX 실험 자동 기록·체험 회원 검수 — 2026-10-14

이번 변경은 `codex/voku-ux-study`와 `voku-ux-study.pages.dev`에만 적용한다. 기존 운영 `main`, 회원·게시글 DB는 변경하지 않는다.

## 동작

- 카카오 진입 버튼은 실제 OAuth 요청 없이 탭 안의 `체험 회원`으로 로그인하고 원래 화면으로 복귀한다.
- 실제 관리자 Auth 세션과 체험 신원을 분리한다. 공개 콘텐츠는 인증을 사용하지 않는 읽기 클라이언트로 가져온다.
- 글쓰기 직접 주소도 제한 안내를 표시한다. 댓글·답글 입력을 제공하지 않고 업로드·프로필 변경·신고·관리 쓰기는 차단한다. 최종 Supabase 요청 단계에서도 읽기·관리자 인증 외 쓰기를 거부한다.
- 추천·스크랩은 현재 탭에서만 동작하며 로그아웃하면 초기화된다. 실제 조회수는 올리지 않는다.
- 기록 여부 선택과 하단 고정 버튼을 제거했다. 접속 즉시 임의 방문 ID로 기록하며 푸터와 전체 메뉴 중앙에 `UX 테스트 버전`을 표시한다.
- 푸터에 자동 기록과 IP 수집 사실을 안내한다. 입력 내용, 검색어, 계정 ID, 비밀번호·인증 토큰은 수집하지 않는다.
- 별도 D1에 방문별 마지막 접속 IP를 저장하고 기존 실제 admin만 조회한다. v1의 과거 방문은 IP를 소급 수집하지 않는다. 새 v2 클라이언트만 IP를 기록한다.

## 확인

- `npm test` 181개 통과. 더미 로그인·재진입·쓰기 차단·읽기 허용, 자동 세션, 서버 IP 검증, IPv4/IPv6, admin 권한, 구버전 무-IP 수집, 30일 이전 IP 정리, 스키마 재적용 포함.
- `npm run check`, `npm run build` 통과. 아카이브 5,330문서·66,010쪽 검증 유지.
- 실제 390×844에서 선택 UI 없이 첫 방문 이벤트가 로컬 D1에 생성됨을 확인했다.
- 카카오 클릭 후 외부 이동 없이 체험 회원으로 복귀했고, 새로고침 후에도 체험 상태가 유지됐다.
- 전체 메뉴 제목의 가로 중앙은 195px(390px 화면), 문서 폭은 390px. 선택 패널·고정 기록 버튼 없음.
- 글쓰기 직접 진입은 제한 안내, 글/파일 입력 0개. 목록 복귀 동작 확인.
- 게시글 이미지 읽기, 댓글 작성 제한, 더미 추천 0→1, 스크랩 후 내 프로필의 게시글 1개 표시 확인.
- 공개 읽기 API에서 같은 글의 운영 조회 0·추천 0·댓글 0 유지 확인. 체험 조작이 기존 DB에 반영되지 않았다.
- 320×740에서 프로필 입력 비활성화 확인. 문서 폭 320px, 가로 넘침 없음.
