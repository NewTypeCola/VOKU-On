# 커뮤니티 UX 개선 기록

## 2026-10-11 적용 범위

- 목록 말머리와 공지 사이의 설명 영역 제거.
- 말머리는 전체, 자유글, 추억, 질문, 동문소식, 공지로 정리. 기존 `일상`, `음악` 글은 데이터를 변경하지 않고 자유글로 표시한다.
- 큐시트 연결 여부는 말머리와 분리해 별도 표시·필터로 제공한다. 기존 `자료 이야기` 링크도 연결글 필터로 해석한다.
- 공지는 텍스트 배너로 가로 스크롤하며, 여러 공지가 있을 때 이전·다음 버튼과 현재 위치를 표시한다.
- 검색을 열면 검색 입력에 바로 포커스한다.
- 댓글 입력과 ‘목록으로’ 사이의 이어 읽기 위치를 유지한다. 현재 글 앞뒤를 포함한 최대 5개 글을 압축 표시하고, 좌우 버튼으로 5개씩 이동한다. 마지막 묶음은 5개를 채우기 위해 앞 묶음과 일부 겹칠 수 있다.
- 이어 읽기는 원래 목록의 말머리·검색·정렬·큐시트 필터를 따르며, 20개 단위의 목록 페이지 경계에 제한되지 않는다. 공지에서는 다른 공지를 보여준다.
- 댓글과 답글 모두 구분선을 사용하고, 답글의 별도 배경색과 화살표를 제거한다. 작성 시각은 한국 시간 월·일·시·분으로 표시한다. 답글 깊이는 1단계로 유지한다.
- 댓글 동작과 취소 버튼은 최소 44px 높이로 제공한다.
- 목록에서 글쓰기에 진입하면 해당 말머리를 기본 선택한다. 내용이 있는 임시저장 글은 복구하고, 비어 있는 자동저장은 새 진입 말머리를 덮어쓰지 않는다. 돌아가거나 등록한 글에서 목록으로 이동하면 원래 목록 조건을 유지한다.

회원·인증·관리자 기능 및 글쓰기 첫 화면 재설계는 이번 범위에서 제외한다.

## 내부 후속 과제 — 공지 이미지 배너

**추후 업데이트 예정. 이번에는 구현하지 않는다.**

이미지 배너가 필요한 시점에 이미지 선택 방식, 권장 비율, 모바일 자르기, 대체 텍스트, 저장소와 교체·삭제 정책을 함께 정한다. 현재는 이미지 필드·업로드·이미지 렌더링을 추가하지 않는다.

## DB 및 검증

- `20261011063428_community_ux_navigation.sql`: 기존 게시글을 보존하며 목록 필터와 5개 이어 읽기 RPC를 추가한다. 기존 4개 인자 목록 호출도 유지한다.
- 공개 응답은 기존 비밀글 판정·JSON 직렬화를 재사용한다. 차단·숨김, 비밀글 검색·연결글 제외, 작성자·기존 운영진 열람 동작을 회귀 테스트한다.
- 자동 테스트: 목록 경계를 넘는 앞뒤 조회, 끝 구간, 검색·말머리·연결글 조합, 정렬 동률, 기존 API 호환, 글쓰기 복귀 경로, 한국 시각 표시.

### 확인 결과

- 자동 테스트 90개 통과. 타입·원본 자료 보존 검사, 운영 빌드, 성능 예산 검사 통과.
- 320px·390px 브라우저에서 가로 넘침 없음. 검색을 열면 입력 포커스, 댓글·답글 구분선/동일 배경/시·분, 댓글 조작 버튼 44px 확인.
- 로컬 체험에서 질문 목록의 글쓰기 말머리 상속, 다른 말머리에서 재진입한 임시 글 복원, 글 등록 후 원래 목록 복귀 확인.
- 로컬 공지 2개로 가로 이동, 첫·마지막 버튼 상태, 두 줄 긴 제목 확인. 운영에 테스트 공지를 추가하지 않음.
- 이어 읽기 끝 구간 왕복 검증: `2–6 → 7–11 → 9–13 → 7–11`. 경계에서 이전에 보던 묶음으로 돌아온다.
- 운영 DB 적용 이력: `20261011073850 community_ux_navigation`. 일반 글 31개·공지 1개 보존. 익명 조회로 20번째 글이 가운데 놓이고 다음 페이지 글까지 이어지는지, 비밀글 본문이 가려지는지 확인.
- Security Advisor의 공개 `SECURITY DEFINER` 알림은 새 읽기 RPC에 대해 익명/회원 각각 1개 증가한다. 기존 비밀글 판정과 직렬화를 재사용하는 의도된 진입점이며, 내부 후보 조회 함수의 직접 실행은 허용하지 않는다. 그 외 기존 알림은 변동 없다. [공식 점검 설명](https://supabase.com/docs/guides/database/database-linter)

## 2026-10-11 글쓰기 화면 전면 개편

- 제목·본문 중심의 한 화면 작성. 상단에는 뒤로가기, 새로쓰기, 등록(수정 시 수정 완료)을 두며 스크롤 중에도 유지한다.
- 전체/본문 미리보기, 글꾸미기, 서식 도구와 더보기 메뉴는 제거한다. 새 글은 일반 텍스트로 저장하며 기존 게시글·초안의 `bodyFormat`은 보존한다.
- 말머리와 공개 범위를 한 줄에 배치한다. 비밀글의 작성자·기존 운영진 열람 규칙, 등록 후 공개 범위 변경 금지, 기존 공지 설정을 유지한다.
- 사진·큐시트 버튼은 본문 아래에 둔다. 사진이 추가되면 순서·제거·대표 사진 안내를 표시하고, 형식·용량 설명은 접어서 제공한다. 큐시트 연결은 자동 포커스되는 검색으로 시작한다.
- 제목·본문 누락이나 길이 초과는 해당 입력칸 옆에 알리고 첫 오류로 포커스한다. 등록·초기화의 중복 실행을 막고, 등록 실패 시 글과 사진을 보존한다.
- 작성 내용이 있을 때만 자동 저장 상태를 표시한다. 기기 내 텍스트·사진 임시 저장, 복원 알림, 미저장 상태의 이탈 경고, 원래 목록 조건과 스크롤 복귀는 유지한다.
- 새로쓰기는 확인 후 현재 화면에서 초기화한다. 수정 중에는 임시 수정본을 지우고 서버의 현재 글을 다시 불러온다. 페이지 새로고침에 따른 이탈 경고 충돌을 제거한다.
- 회원·인증·관리자 기능과 DB 구조는 변경하지 않는다. 배포에 DB 마이그레이션이 필요하지 않다.

### 검증

- 자동 테스트 92개: 기존 권한·사진 저장·비밀글·읽기 흐름 회귀, 새 입력 검증, 기존 서식 초안 보존. 타입·원본 자료 보존 검사, 운영 빌드, 성능 예산 통과.
- 로컬 배포 빌드의 390px·320px에서 가로 넘침 없음. 작성 상단 버튼 44px, 30줄 본문 자동 확장과 스크롤 중 상단 고정 확인.
- 제목/본문 누락 포커스, 큐시트 검색 자동 포커스, 사진 2장 순서 변경, 텍스트·사진·큐시트·비밀글 초안의 새로고침 및 목록 왕복 복원 확인.
- 로컬 체험 글 등록 후 본문 기호를 일반 텍스트로 표시하고, 사진·연결 자료·원래 질문 목록 경로를 유지하는지 확인.
- 새로쓰기 취소 시 내용 보존, 확인 시 빈 글로 초기화, 수정 중 새로쓰기 시 등록된 본문·사진으로 복구 확인.
- 브라우저 검증의 글·사진 등록은 별도 로컬 체험 저장소에서 수행한다.
